# IODeviceManager

One API for the devices an application operates: discover, connect, configure and use scanners, cameras and printers, each behind the same `IODevice` lifecycle and error reporting. Printers work on Linux, macOS and Windows through CUPS and the Windows spooler, with GutenPrint as an alternative renderer; scanners work through SANE on Linux and eSCL network scanning on every platform; webcams work through V4L2 on Linux. Devices plugged in or out are followed on Linux when it is built with libudev. Microphones, speakers, storage, serial ports, GPIO and the remaining platform backends are planned — see Gaps.md for what is built.
