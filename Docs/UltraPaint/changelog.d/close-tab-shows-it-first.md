- **Closing a tab that is not on show brings it to the front first.** The
  tab's **×** now shows the image it closes and asks "Close *name*?" before
  it goes, so a click on the wrong tab's cross loses nothing. A tab with
  unsaved changes is still asked about with "... has unsaved changes. Close
  it anyway?"; the tab on show, without changes, still closes at once, as
  does *File ▸ Close Tab* (`Ctrl+W`) on it.
