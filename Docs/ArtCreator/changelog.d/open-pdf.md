- **ArtCreator opens PDF files, on the PDF's page format.** File > Open, a
  file dropped on the window and the command line take a `.pdf` (in a build
  with MuPDF): the page becomes the drawing's page - its size and orientation
  as a PDF viewer shows it - and its shapes, text and pictures become objects
  to edit. A PDF of several pages opens its first, and the status bar names
  what could not be carried over (framework, *A PDF opens as an editable
  drawing, on its own page format*).
