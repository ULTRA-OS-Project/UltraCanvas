- **ChatCube's text can be translated.** Every label, button, menu, field
  hint, status line, dialog and the Settings and Edit profile windows go
  through UltraLocalisation, collected in `media/locale/en/ChatCube.json`;
  a sentence with a name or a reason in it is one entry with a placeholder
  ("Could not fetch {0}: {1}"), not pieces glued together, and counts are
  plural forms ("1 member", "2 members", "1 byte"). With no translation
  yet, everything shows in English as before.
