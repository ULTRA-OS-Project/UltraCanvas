- **Started with a file, the window appears at once**, showing a turning ring
  and the file's name instead of waiting for the folder to be read - and
  never *No media*, which is now only for a viewer started with nothing
  (`OpenFileWhenShown` and its kin, see the framework changelog). A second
  start's files are shown the same way.

  <version>`, following the arrow keys.
