- **Edit in UltraPaint.** Right-clicking a picture - or a selection of
  pictures - offers *Edit in UltraPaint*, right after *Open with*. It opens
  them in UltraPaint, in the window open already if there is one. The entry
  is there only where UltraPaint is installed beside UltraFiler, and in
  MobilePC, which carries UltraPaint itself; a picture inside an archive or on
  a remote drive does not get it.
