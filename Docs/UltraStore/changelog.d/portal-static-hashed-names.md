- **The portal's pages no longer come up with the stylesheet of the release before** (`Server/UltraStorePortal` 0.3.1). After the update that moved the pages to Bootstrap, a browser that had visited the store before drew the new pages with the `portal.css` it still held - the web server lets it keep static files for a day, and the file's address had not changed - and the developer console collapsed into one narrow column. Outside `DEBUG` every static file is now linked under a name that carries a hash of its content (`portal/portal.3f2a9c1b7d4e.css`; Django's `ManifestStaticFilesStorage`, written by the `collectstatic` the service runs on every start), so an update's stylesheet and script have addresses no browser has seen. A developer's machine and the tests serve the files under their own names, with no manifest to make.
