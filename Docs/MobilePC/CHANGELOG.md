#### 2026-11-25 *0.1.1*
- **Edit a picture in UltraPaint, a drawing in ArtCreator, from UltraFiler.**
  Right-click a picture in UltraFiler on the TV and choose *Edit in
  UltraPaint*, or a drawing and choose *Edit in ArtCreator*: the editor opens
  it in a window beside it.
- **ArtCreator opens and saves drawings.** SVG, Illustrator, DXF and DWG,
  EMF and WMF, and OpenDocument drawings - before, ArtCreator in MobilePC
  could draw but said on Open and Save that it had no file formats.
- **UltraFiler on the TV.** The file manager is now one of MobilePC's
  applications: the taskbar's UltraFiler button, the RAM disc button and the
  Apps window start it, in a window on the desktop like the others. It opens
  the phone's storage - Download, Pictures, DCIM, Documents - and the first
  time it starts it asks whether it may show all of the phone's files; the
  switch itself is Android's, on the phone's screen. Starting it again while
  it is open opens the folder in a new tab of that window, as on a computer.
  Remote drives and RAM discs are not in this version.
- **Applications start each other.** A double-click on a picture, a video or
  a song in UltraFiler opens it in UltraViewer, and the desktop's buttons that
  start a program by name start the application inside MobilePC instead of
  looking for a program that is not there.

#### 2026-11-24 *0.1.0*
- **MobilePC: UltraDesktop on a TV or monitor, run by an Android phone.** The
  first version. Connected to an external display - a USB-C cable or dock, or
  a wireless display the phone offers for a second screen - the desktop is
  drawn there in full size: UltraDesktop with its taskbar, its Apps window and
  the applications it starts, each in a window that can be moved, resized,
  minimised and maximised. The phone becomes the control pad: a touchpad (one
  finger moves the pointer, a tap clicks, two fingers scroll, a tap with two
  fingers is the right button), left and right buttons, and a keyboard button
  that brings up the phone's keyboard to type into the window in front. A
  Bluetooth or USB mouse and keyboard work too. With no display connected the
  desktop is on the phone's own screen.
- **The applications it carries:** UltraTexter, UltraViewer, UltraPaint and
  ArtCreator, started from UltraDesktop's Apps window, all in the one program.
  UltraFiler follows.
