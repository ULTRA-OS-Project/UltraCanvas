- **Edit a picture in UltraPaint, a drawing in ArtCreator, from UltraFiler.**
  Right-click a picture in UltraFiler on the TV and choose *Edit in
  UltraPaint*: UltraPaint opens it in a window beside it. *Edit in ArtCreator*
  follows for drawings once MobilePC's Android build reads vector files (the
  Vector plug-in is not built for Android yet, so the entry does not show
  there today).
