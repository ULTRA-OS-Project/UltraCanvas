# Apps/UOSSettings

UOS-Settings, the ULTRA OS settings application. See
[`Docs/UOSSettings/README.md`](../../Docs/UOSSettings/README.md).

| File | What it is |
|---|---|

| `../UltraDesktop/ui/UltraDesktopSettings.cpp` | Compiled in: the desktop's settings file, for the Desktop page |
| `UOS-Settings.desktop` | Freedesktop entry |
