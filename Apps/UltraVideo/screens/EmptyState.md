The timeline's state when it has no clips: it invites the user to drop media and changes while files are dragged over it.

**Consumer provides:** the import and add-music actions, and the drag-over file count.

- Idle: a dashed `line-strong` drop zone in `radius-lg`, a `display` headline, one sentence and two buttons (Import media as primary).
- Drag-over: a solid `focus` border, `drop-soft` fill and the count of files to be added.
