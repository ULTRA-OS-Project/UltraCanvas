Standard, primary, ghost, icon and toggle buttons, all `control-h` tall.

**Consumer provides:** a label and/or an icon, a variant, and the pressed state for toggles.

- Use one primary button (`accent`, `on-accent`) per window: Export in the app bar, or the main action of a dialog.
- Toolbars use ghost icon buttons. A toggle that is on uses `accent-soft` with an `accent` icon.
- Destructive buttons use `danger` text, never a red fill.
