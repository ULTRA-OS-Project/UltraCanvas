# ULTRA OS documentation

ULTRA OS is built in stages: the UltraCanvas framework first, the
applications on top of it, the operating system around them. These pages
are the example site's documentation, written in Markdown and published by
UltraPress as HTML + JavaScript.

Start with [building the framework](build/framework.md), then
[write an application](build/application.md#the-window).
